Unit 1: Introduction and Recap of OOP

Advanced Object-Oriented Design and Programming

Unit Overview

Unit 1 provided a recap of the fundamental principles of Object-Oriented Programming (OOP), including inheritance, polymorphism, abstraction and encapsulation, together with constructors and destructors. The unit strengthened my understanding of how these concepts support the development of reusable, maintainable and scalable software.

The practical exercises provided an opportunity to apply these principles in Python rather than considering them only from a theoretical perspective. This included creating class hierarchies, implementing polymorphic behaviour, applying abstraction and encapsulation, and working with object construction and finalisation.

From a security perspective, the unit also highlighted the relationship between software design and secure development. In particular, concepts such as encapsulation and abstraction demonstrated how access to data and implementation details can be controlled within software.

Learning Outcomes

After completing this unit, I was able to:

  • Revisit the four main OOP principles through practical Python examples.
  • Understand how classes, objects, constructors, destructors and access control influence object behaviour.
  • Apply OOP principles in simple programming exercises.
  • Recognise how OOP supports reusable, maintainable and secure software.
  • Understand how encapsulation and abstraction can support controlled access to data.

Reflection

Although I have previous programming experience, the practical exercises strengthened my understanding of how inheritance, encapsulation, abstraction and polymorphism are applied in Python and how these concepts work together within software. These concepts serve as a solid foundation for understanding and utilising more advanced features of the language in the coming units.

As my professional background is in Cyber Security, I found it particularly interesting to relate these concepts to secure software development. The unit reinforced the importance of considering security during the design and coding stages rather than focusing only on identifying vulnerabilities after software has been developed. The NIST Secure Software Development Framework recommends integrating security practices throughout the software development lifecycle, including reviewing software design and analysing source code before release (NIST, 2022). Encapsulation was particularly relevant to me, as controlling access to an object's internal data can help prevent unintended modification and reduce unnecessary exposure of implementation details (Zhuang, Kuo and Tseng, 2024).

Professional Skills Development and Action Plan

This unit improved my ability to apply OOP concepts in practical programming and to consider maintainability, scalability and security when designing software.

Looking ahead, I intend to apply these concepts when developing security tools and automation scripts. Whether creating vulnerability assessment utilities or security monitoring solutions, following sound object-oriented design principles should help me develop software that is more structured, reusable and easier to extend.
