Unit 1: Introduction and Recap of OOP

Advanced Object-Oriented Design and Programming

Unit Overview

Unit 1 provides a recap of the fundamental principles of Object-Oriented Programming (OOP). The unit focuses on inheritance, polymorphism, abstraction and encapsulation, together with constructors, destructors and access control. It also considers how these principles contribute to the development of reusable, maintainable, scalable and secure software systems.

Learning Outcomes

  • Understand and explain the five OOP principles: inheritance, polymorphism, abstraction and encapsulation.
  • Describe the role of classes, objects, constructors, destructors and access control in OOP.
  • Apply OOP principles to develop basic class hierarchies.
  • Recognise the importance of OOP in large-scale and secure software design.

Key Concepts

Inheritance

Inheritance allows a new class to reuse and extend the attributes and methods of an existing class. It supports code reuse and the creation of logical class hierarchies between general and more specialised classes (Ambler, 2004).

Polymorphism

Polymorphism allows objects of different classes to respond to the same operation in different ways. This enables different implementations to be accessed through a common interface and supports flexibility and extensibility in object-oriented systems (Ambler, 2004).

Abstraction

Abstraction hides unnecessary implementation details and exposes only the essential characteristics and operations required by other parts of the system. This helps manage software complexity by separating an object's external behaviour from its internal implementation (Ambler, 2004).

Encapsulation

Encapsulation groups an object's data and methods within a class and controls how its internal data can be accessed or changed. This supports information hiding and helps maintain the integrity of an object by reducing unnecessary dependencies on its internal implementation (Ambler, 2004).

Constructors and Destructors

Constructors initialise an object's state when it is created, while destructors support object finalisation and cleanup at the end of an object's lifecycle (Rangisetti, 2024).

Reflection

Unit 1 provided the opportunity to revisit the core principles of Object-Oriented Programming from a more advanced perspective. Although I have previous programming experience, the practical exercises helped demonstrate how inheritance, encapsulation, abstraction and polymorphism are applied in Python.

As my professional background is in Cyber Security, I found it particularly interesting to relate these programming concepts to real world security applications. From my perspective, secure software development should not focus only on finding vulnerabilities after the software is built. Security also needs to be considered during the design and coding stages. Hughes and Robinson (2024) highlight the importance of following defined security requirements, applying secure coding practices such as input validation and avoiding unsafe functions, and reviewing reused code for security issues. This strengthened my view that security should be built into the development process from the beginning rather than treated only as a later testing activity. For example, understanding encapsulation highlighted the importance of protecting sensitive data and controlling access to critical information within software systems (Zhuang, Kuo and Tseng, 2024).

Looking ahead, I intend to apply these concepts when developing security tools and automation scripts. Whether creating vulnerability assessment utilities or security monitoring solutions, I believe that following sound object-oriented design principles will help me produce software that is more reliable, scalable and easier to extend.
