Advanced Object-Oriented Design and Programming

MSc Cyber Security e-Portfolio | University of Essex

Module Overview

This module develops advanced knowledge of object-oriented analysis, design and programming. It explores how object-oriented principles and design patterns can be used to create secure, reusable, maintainable, flexible and scalable software systems.

Module Learning

  • Secure coding practices in software development.
  • Advanced object-oriented principles for complex software problems.
  • Reusable and maintainable software through design patterns.
  • Secure and robust software architectures for larger systems.
  • Software solutions that can support AI and data science applications.
